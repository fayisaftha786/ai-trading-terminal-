REAL MODE · Coinbase Advanced account connection

LIVE LOCKED

REAL mode supports Coinbase account preflight and manually confirmed SPOT LIMIT GTC post-only BUY/SELL orders only when the owner enables the guarded execution secret. Every order requires a fresh preview and a separate confirmation. Automatic live entries and withdrawals are never enabled. Store CDP credentials only as Cloudflare Worker secrets; never enter them in this page or chat. Keep Transfer permission OFF.

Setup: create a Coinbase CDP API key with View permission; Trade is optional and only needed for explicitly confirmed manual limit orders. Keep Transfer disabled. The connector supports current Ed25519 Base64 keys (32/64-byte forms), Ed25519 PKCS#8 PEM and legacy ECDSA P-256 PEM. Add only these to Cloudflare Worker Secrets: COINBASE_ADVANCED_API_KEY (the full CDP API Key Name), COINBASE_ADVANCED_API_SECRET (the private key), COINBASE_ADVANCED_ALLOWED_PRODUCTS (for example BTC-USD,ETH-USD), and COINBASE_ADVANCED_MAX_ORDER_QUOTE (a small quote cap). Keep COINBASE_ADVANCED_ORDER_ENABLED=false while testing the connection; no live orders are created by the account sync.

Every preview is bound server-side to its exact product, side, size, limit price and fee. It expires after 60 seconds and can authorize only one manual confirmation; the submit request cannot change the previewed order details. Real-money auto-entry is not enabled.

Automation controls

AUTO OFF
Waiting for first scan

Automatic PAPER entries are OFF by default. The live AUTO status above is authoritative and changes after the owner explicitly enables or disables entries. Enable only after a recent complete scheduled scan confirms all configured markets, fresh same-provider quotes/books/candles and the risk gates. Once enabled, the Durable Object alarm monitors approximately every 90 seconds while the service and public providers are available. It permits one open position at a time and up to five completed BUY→SELL cycles per UTC day; five is a ceiling, not a target. Per-position notional is capped at $8 with $2 kept unallocated. Entry sizing uses a 60 bps/side paper-fee assumption, 10 bps/side slippage and observed spread; dynamic take-profit must clear estimated round-trip costs. Daily loss guard is 1% ($0.10 at starting equity), with a 0.75% soft pause. Watchdog recovery restores auto-entry only when the owner’s prior opt-in permission is still recorded. Owner emergency stop and drawdown halt never auto-resume. This is periodic paper monitoring, not tick-level real-time execution or a guaranteed uptime service. Live order execution remains hard-locked.
