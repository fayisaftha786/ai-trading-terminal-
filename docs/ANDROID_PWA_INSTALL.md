# Install the Cloud Edition PWA on Android

1. Deploy the private cloud backend using `docs/CLOUD_DEPLOYMENT_NO_TERMUX_MALAYALAM.md`.
2. Open the deployed HTTPS URL in Chrome on Android and sign in.
3. Open Chrome menu → Install app / Add to Home screen.
4. Launch the installed app and sign in again if the browser tab session has expired.

The PWA is a dashboard client only. Market data and paper trading controls require the cloud service to be running. It does not run Python on the phone.
